# OS Learning Repository

This repository contains C programs designed for learners who want to understand Operating Systems concepts.

## Instructions

1. Clone the repository.
2. Compile the C programs using a C compiler (e.g., `gcc`).
3. **Important:** Please store your compiled executable files (`.exe`) in the `output/` directory.

## Directory Structure

- `output/`: This directory is intended for storing compiled executables.
- `*.c`: Source code files for various OS algorithms and concepts.

## Example Compilation

To compile `10.c` and store the output in the `output` directory:

```bash
gcc 10.c -o output/10.exe
```
